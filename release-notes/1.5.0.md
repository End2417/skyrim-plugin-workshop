# Skyrim ESP Editor v1.5.0

This release adds undo and redo, new and copied records, a file header editor, plugin health and load order conflict checks, a script report, plugin comparison, a much stronger bulk edit, strings read straight from the game’s archives, an update check and a new look, for Skyrim Legendary Edition plugins on Android.

**Back up your plugins before editing them.**

## What’s new

- **Undo and redo.** New buttons in the toolbar, plus Ctrl/Cmd+Z and Ctrl/Cmd+Shift+Z when no text box has the focus. They cover field edits, reverting a record, deleting and creating records, bulk edits, header edits and removing identical records. Quick edits to one record while you type count as one step, and a bulk edit is one step.
- **New record and Copy.** The wrench menu’s **New record** makes an empty record of a chosen type with its own FormID, in the right group (made if the plugin has none yet). **Copy** on a record makes a new record with the same fields right behind it, under a new Editor ID. The header’s record count and next object ID are kept in step, and records you created survive Android closing the app, because they are kept in the draft.
- **File header.** Edit the author, the description, the ESM and ESL flags and the spelling of a master’s file name. A master can be added only to a plugin that has no records of its own.
- **Plugin health.** Tells you whether the plugin fits the light-plugin (ESL) window (new records with IDs 800–FFF, or 001–FFF with header version 1.71) and lists the ones that do not, and can set the ESL flag. It also lists records that share an Editor ID or a FormID, groups whose parent record is missing, and new supporting records (shouts, textures, projectiles, lists…) that nothing else in the plugin points at.
- **Load order conflicts.** Add the plugins you load together, put them in load order, and see which records more than one of them changes, who wins, and what the overwritten versions had. Masters such as `Skyrim.esm` do not need to be added. Nothing is changed.
- **Scripts report.** The code button lists the Papyrus scripts the plugin uses, on records, quest aliases and dialogue or package fragments, and which well-known libraries they come from (SkyUI, MCM Helper, JContainers, PapyrusUtil, Papyrus Extender and a few more, by name only) with what those need installed, such as SKSE. It flags script properties filled with a FormID that points at a master the plugin does not list or at a record that is not there. **Copy .pex list** gives you the script names to look for. Use it to find out why a converted mod loads but does not work.
- **Compare.** The arrows button compares the open plugin with another and lists the records added, removed and changed, with the changed fields shown before and after. Read it **against its master** (what a mod changes in `Skyrim.esm`, including overrides identical to the original) or as **two versions** (for example the Special Edition and Legendary Edition copies of a mod). The form version and timestamps are ignored, and unsaved edits count. In master mode you can **remove the records that are identical to the master (ITM)** in one step.
- **Bulk edit, upgraded.** Change several fields in one run (one change per field). Choices (enums) and flags can be set, turned on or turned off, not just numbers. **Export CSV** writes the records and their values, and **Import CSV** brings edited numbers back as a previewed change, matched by FormID or Editor ID. **Presets** save a set of changes and the words that narrow the records down, to use again later. Applying is one undo step.
- **Strings from the game’s archive.** Skyrim keeps its names in `Skyrim - Interface.bsa`. When no extracted strings files are found, setup and Check plugin take them out of that archive by themselves (it is only opened when a localized plugin needs it), and you can pick any `.bsa` where strings files are asked for. Both archive types are read: Legendary Edition (zlib) and Special Edition (LZ4).
- **Back up the original before saving.** On Android, and on by default (switch it in the folder dialog). The first time you save a plugin, the file exactly as you opened it is also saved next to the result as `Name.esp.bak`. Saves never overwrite anything, so this mainly protects you when you copy the saved file over the original yourself.
- **Update check.** When the app opens, it asks GitHub whether a newer release is out (at most once a day, a couple of seconds after startup so it never slows the start). If there is one, a dialog shows the release notes and offers **Download** or **Later**. If you choose Later it asks again at the next daily check. It stays silent when you are offline or GitHub does not answer. In the About screen (info button) you can see the version you have, turn the check off, and use **Check now**.
- **More record layouts.** Voice Type, Equip Type, Location Reference Type, Action, Texture Set, Encounter Zone, Shout, Word of Power, Actor Value Information, Sound Category, Dialog Branch and Addon Node now show readable fields. Where the meaning of a field was not certain it is shown as a plain number or hex rather than named.

## Changes

- **New color scheme.** A dark periwinkle palette taken from the Skyrim Mod Manager: near-black page, slightly lighter cards, a lighter surface for dialogs, a periwinkle accent, soft pink for delete. Secondary buttons are a medium periwinkle so they never look disabled. The unsaved-changes green and the warning amber are unchanged.
- **Tools menu.** A wrench button in the toolbar holds New record, File header, Plugin health and Load order conflicts.
- **Extract and new records.** A record you create or copy does not exist in the original plugin. **Extract** now writes it as a new record of the extracted plugin, with a new FormID, and renumbers the fields that point at it. A chosen record that points at one brings it along. When you add records to an existing patch, they get FormIDs the patch does not use yet.
- **Bulk edit shows more.** The preview names choices and flags instead of showing their numbers.

## Known issues

- Masters cannot be reordered or removed, and a master can be added only to a plugin that has no records of its own. Doing it otherwise renumbers every FormID of the plugin’s own records and every reference to them, and the editor only knows the reference fields of the record types it has layouts for.
- A new record starts with its Editor ID and the few fields the game needs; add the rest from its field list. Records with child groups (cells, worldspaces, dialogue topics) and placed references cannot be copied.
- A reference to a new record inside a script property, or in a field the editor has no layout for, is not renumbered when you extract.
- The script report follows the community documentation of the script data format and has not been checked against a large set of real mods. A record whose script data does not read is listed as unreadable, never guessed at. Libraries are recognised by name only, and fragment scripts of scenes, perks and terminals are not listed.
- Plugin health’s “nothing points at it” list is a lead, not proof. Scripts and other plugins can use those records, and records of types the editor has no layout for were not read.
- The light-plugin check only looks at the IDs of new records. The editor cannot renumber them for you; xEdit’s “Compact FormIDs for ESL” does.
- If two plugins in the load order conflicts screen list different masters, references inside records can look changed although they point at the same record.
- Opening a `.bsa` reads the whole archive into memory first.
- The undo history covers the open file, up to 200 steps, and starts fresh when you open another file or restore a draft.
- The update check only tells you about a newer release; you download and open the APK yourself. GitHub sees the phone’s IP address, as with any web request.
- Nothing here has been tested in the game. Test edited, extracted and converted plugins in xEdit or in the game before relying on them.
- All other known issues are unchanged from v1.4.0.

## Upgrade notes

- Install this APK over v1.4.0. Do not uninstall first if you want to keep your settings and remembered masters.
- Your plugins are not changed by this update. Records you edit are only written when you save or extract, and saving never overwrites a file.
- The first time you save a plugin, the app also saves a `.bak` copy of the original next to it. Switch this off in the folder dialog if you do not want it.
- The app now looks for newer releases when it opens. Turn that off in the About screen if you prefer.
