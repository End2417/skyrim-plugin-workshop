# Skyrim ESP Editor v1.6.1

This release fixes two problems in **Merge plugins**, makes merging faster and lighter on memory, and checks that damaged plugin files are always refused with a clear message, for Skyrim Legendary Edition plugins on Android.

**Back up your plugins before editing or merging them.**

## What’s new

- **Fixed: a stale choice could be applied to the wrong plugin.** In the merge preview, tapping a plugin to use its value where two plugins disagree is remembered by position in the list. Adding, removing, moving or sorting the plugins did not clear those choices, so after a change a choice could silently apply to a different plugin or record. Any change to the list of plugins now clears them. Switching options, or adding originals, keeps them.
- **Fixed: long pauses during a big merge.** The merge handed control back to the screen after every few dozen records. Android’s web view makes each of those hand-backs wait at least a few milliseconds, which added up to seconds for a merge with many shared records. It now hands control back about once per frame of work, and the progress bar updates a few times a second instead of dozens.
- **Less memory when reading `Skyrim.esm`.** When a merge reads `Skyrim.esm` (and `Update.esm`) from your Skyrim folder, only the records that are compared are now kept while the Merge dialog is open, instead of the whole parsed file. Opening the dialog again reads the files again, and nothing of them is stored between sessions. If you add or change plugins so that other records have to be compared, the file is read again for those.
- **Faster merging.** Renumbering the references inside records no longer allocates objects for every record. In a test with two generated plugins of 100,000 records each, building the merged plugin took about 30% less time.

## Changes

- **Tests for damaged plugins.** Plugins with corrupted or cut-off data are fed through reading, field decoding, Check plugin and merging. They are refused or read with ordinary error messages, never with a raw program error, and never hang. These checks now run with every change to the project.
- **More merge tests** for compressed records, unsaved edits in the open plugin, references moved between a cell’s persistent and temporary groups, empty plugins, duplicated FormIDs, differently cased master names, too many masters and deleted records. None of them found a further problem.
- **The separate test build was removed from the project.** This does not change the app: it already used the normal app ID, name and save folder.

## Known issues

- Reading `Skyrim.esm` for a merge still takes a while on a phone the first time, and needs memory while it is read. Only the records that are compared are kept afterwards.
- This release has been checked on generated plugins and with automatic tests, not on the phone and not against a large set of real mods. Try a small pair of mods you can verify first, and test merged plugins in xEdit or in the game before relying on them.
- All other known issues are unchanged from v1.6.0.

## Upgrade notes

- Install this APK over v1.6.0. Do not uninstall first if you want to keep your settings and remembered masters.
- Your plugins and settings are not changed by this update.

## Feedback

When reporting a problem, include:

- Android version and device model
- The plugins you merged and where they come from
- Steps that caused the problem
- The exact error message shown by the app
- Screenshots when available
