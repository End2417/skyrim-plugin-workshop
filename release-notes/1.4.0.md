# ESP Editor 1.4.0

This release adds Special Edition to Legendary Edition conversion, so plugins made for Skyrim Special Edition can be used with the Legendary Edition game, including the Android port.

## What's new

### Special Edition to Legendary Edition
- **To LE** button makes a Legendary Edition copy of a Special Edition plugin. It sets the header version to 0.94 and the record form version to 43, clears the light plugin (ESL) flag, renames `.esl` masters to `.esp`, and warns about Creation Club masters. Record contents stay byte-identical, and your open file is never changed.
- Lists fields that are longer than the Legendary Edition layout the editor knows, with an experimental option to trim them (off by default).
- **Strings files:** for a localized plugin, add its `.STRINGS`, `.DLSTRINGS` and `.ILSTRINGS` files and To LE re-encodes their text from UTF-8 to Windows-1252, which is what Legendary Edition reads. Strings files you loaded earlier for that plugin are reused. Characters Windows-1252 cannot hold (for example Japanese) become `?`, and the dialog counts them. Converted files keep their names; if one already exists the app saves it as `name (1)`, so rename it to match the plugin.
- Checks the converted plugin against any master files the app remembers, and shows the result.
- Shows what a plugin conversion cannot carry over: meshes, textures (BC7), BSA archives, animations and SKSE64 mods.
- Special Edition plugins are recognised when you open them and labelled in the header.
- **Extract** can save in Legendary Edition format when the source is a Special Edition plugin.

### Plugin check (shield icon)
- Flags FormIDs that point at a master slot the header does not list, references to records that do not exist, and records with a bad own FormID. Each problem has a Go to button.
- References into a master can only be verified if you add that master's file in the dialog.
- **Remembered masters:** the app keeps what it needs from each master you add (such as `Skyrim.esm`), so you only add it once, and you can pick several files at once. The ✕ button removes and forgets one.

### Open with (Android)
- Tap a `.esp`, `.esm` or `.esl` in your Files app and choose ESP Editor, both at launch and while the app is running.
- Android has no file type for `.esp`, so the app is also offered for generic binary files. A file that is not a plugin gives the normal "doesn't look like a Skyrim plugin" error.

### Extract
- **Dependencies:** include the records your changes depend on, one to three levels deep, with a checklist so you can drop any of them. They are copied unchanged, which can clash with other mods.
- **Existing patch:** add records into an existing patch plugin. Its master list has to line up with the source's, because FormIDs are never renumbered; if it does not, the dialog says why and blocks the merge.

### Save folder (Android)
- Pick a folder with Android's own folder picker. The permission is kept across restarts. Files are never overwritten. If the folder becomes unavailable, saving falls back to `Documents/ESP Editor` with a message.

### Look and feel
- **Adaptive app icon.** The launcher shapes the icon to its own style (circle, squircle and so on). Android 7 and older get a rounded-corner icon. Reinstall or replace the app to see it; some launchers need a restart to refresh.
- **Pinned buttons.** The toolbar stays at the top while you scroll through a record. The title and status line scroll away.

### Fixes
- On phones, the toolbar buttons no longer run off the screen and force sideways scrolling. They wrap onto a second row when needed, and the page can no longer scroll sideways.

## Things to know
- The check, dependency finder and patch merge only see fields the editor knows are FormIDs. Script properties and condition parameters are not inspected, so "no problems found" is not a guarantee.
- Merging into a patch saves a copy. If the name exists you get `Patch (1).esp` and swap it yourself.
- If a patch lacks a master the source needs, it is only appended when the patch has no records of its own, because appending would shift their FormIDs.
- The Special Edition to Legendary Edition conversion, including strings files, has not been tested in the game. Test converted plugins in xEdit or in the game before sharing them.
- This project was built with AI help and is not fully reviewed. Back up your plugins first.
