# ESP Editor 1.4.0

## What's new

### First-launch setup for Skyrim's own files
- After the credits, the app now offers to set up your Skyrim files. On Android you can **pick Skyrim's folder once** (its `Data` folder, or the folder that contains it) in Android's own folder picker. The app only asks to read, and finds `Skyrim.esm`, `Update.esm`, the DLC masters, the Unofficial Skyrim Legendary Edition Patch (many mods need it as a master) and any extracted strings files by itself. You can also pick files by hand, all in one go.
- The app keeps the record IDs, names and strings on the device, not the plugins themselves. Records then show their names, you can search masters by name when editing a reference, Check plugin knows what exists, and opening `Skyrim.esm` later already has its names loaded.
- Skyrim normally keeps its strings inside `Skyrim - Interface.bsa`. If there are no loose strings files in `Data/Strings`, records show Editor IDs without names until you add extracted strings files.
- Skip it and do it later from the info button (**Set up Skyrim files**) or in Check plugin. **Read “<folder>” again** in that screen refreshes from the same folder.
- In Check plugin, **Read masters from Skyrim folder** reads whichever masters the open plugin lists and you have not added yet, whether they are Skyrim's, the Unofficial Patch or another mod in the same Data folder.

### Editing
- **Bulk edit.** The new sliders button changes one number in many records at once, with a preview before anything is written. Pick a record type (Armor, Weapon...), a field (Weight, Value, Damage...), what to do (set, add, multiply, change by %) and a number, and optionally words that the Editor ID or name must contain. The preview lists every record with its old and new value, lets you untick any, and flags values that would not fit. Applying changes marks the records as modified, so you can review or revert them with the checklist button. It works on plain number fields only (not flags, choices or references), and on one field per run.
- **Add another entry right below.** The three-dot menu on a repeatable field (an inventory item, a faction, a spell, an AI package...) now has **Add another … below** and **Duplicate … below**. The new entry lands directly under the one you chose, counters such as the item count update themselves, and an item's extra data stays next to it.
- **Pick a reference by name.** When you edit a field that points at another record, type words such as "steel sword" and a collapsible list of matching records appears. Tap one to fill in its FormID, then apply. Typing a FormID still works.
- **Names from your masters.** The app keeps the Editor IDs, names and types of the records in the masters you add, so that list includes them, and references into a master show as `SteelSword "Steel Sword" [WEAP:00013989]` instead of a bare number. For a localized master such as `Skyrim.esm`, pick its strings files with it. Masters added with an earlier version need adding again.

### Finding records
- **Three search boxes.** The single search bar is replaced by separate **FormID**, **EditorID** and **Name** boxes under the column titles. A record has to match every box you fill in, and each word you type has to appear in that field (plurals and the start of a word count). The FormID box takes part of the hex ID, with or without `0x`. Searching by record type or weapon kind in the main search is gone; the reference picker still understands plain words.
- **Sort the record list.** Tap **FormID**, **EditorID** or **Name** above the list to sort the records inside each group, tap again to reverse, and a third time to go back to the file order. Search results are sorted the same way. Groups where records are followed by their own sub-groups (such as cells) keep the file order so nothing gets separated.

## Things to know
- The first-launch screen shows once. Closing or skipping it counts as done.
- The folder access is new native code. It needs the Android build; it does nothing in the browser version, where you pick the files yourself.
- Reading `Skyrim.esm` the first time takes a little while on a phone. It is kept after that.
