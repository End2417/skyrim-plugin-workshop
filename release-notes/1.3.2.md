# ESP Editor 1.3.2

## What's new

### Strings files in To LE
- For a localized plugin, add its `.STRINGS`, `.DLSTRINGS` and `.ILSTRINGS` files and To LE re-encodes their text from UTF-8 to Windows-1252, which is what Legendary Edition reads. Strings files you loaded earlier for that plugin are reused.
- Characters Windows-1252 cannot hold (for example Japanese) become `?`, and the dialog counts them.
- Converted files keep their names. If a file with that name already exists, the app saves it as `name (1)`, so rename it to match the plugin.

### Remembered master files
- Check plugin now remembers each master file you add (such as `Skyrim.esm`), so you only add it once. You can pick several files at once, and the ✕ button removes and forgets one.
- To LE checks the converted plugin against any remembered masters and shows the result.

### Look and feel
- **Adaptive app icon.** The launcher shapes the icon to its own style (circle, squircle and so on). Android 7 and older get a rounded-corner icon.
- **Pinned buttons.** The toolbar stays at the top of the screen while you scroll through a record. The title and status line scroll away.

## Things to know
- Reinstall or replace the app to see the new icon. Some launchers need a restart to refresh it.
- Converting strings files has not been tested in the game. Test in xEdit or in the game first.
